ทุกคน: สร้างการ์ด
  1. กด + สร้างการ์ด เลือก Ticket (บั๊ก/คำขอ) หรือ Task (งานที่ต้องทำ)
  2. ใส่หัวข้อ รายละเอียด (ขั้นตอนทำซ้ำ ผลที่คาดหวัง) ความสำคัญ และ tag ยิ่งละเอียด Claude ยิ่งแก้ตรงจุด
  3. ใช้ปุ่มกรอง ของฉัน / ยังไม่มีคนรับ เพื่อหางานของตัวเองหรืองานที่ยังไม่มีคนรับ
Dev: รับงานแล้วสั่ง Claude ตั้งค่าครั้งแรก
  1. คลิกชื่อมุมขวาบน → เชื่อมต่อ Claude (MCP) กด คัดลอก แล้วเอาคำสั่งไปรันใน terminal ธรรมดา (ไม่ใช่ในแชตกับ Claude) ไม่ต้อง clone หรือติดตั้งอะไร
  2. ถ้าไม่มีคำสั่ง claude ในเครื่อง ให้เปิดหัวข้อ ไม่มีคำสั่ง claude ในหน้าเดียวกัน แล้วเอา JSON ไปใส่ในไฟล์ ~/.claude.json
  3. เปิด Claude Code ใหม่ แล้วพิมพ์ /mcp เช็กว่า geckoboard ขึ้น connected
  4. Token เป็นของคุณคนเดียว ห้ามแชร์หรือวางในแชต ถ้าหลุดให้กด สร้าง token ใหม่
ทุกครั้งที่ทำงาน
  1. ติ๊กช่องสี่เหลี่ยมที่การ์ดบนหน้าหลัก เพื่อรับงาน (การ์ดย้ายไปกำลังทำ) เลือกได้หลายใบ แต่ การ์ด 1 ใบมีคนรับได้ 1 คน ถ้ามีคนรับไปแล้วจะขึ้นรูปกุญแจและชื่อคนที่รับ ติ๊กออกเพื่อปล่อยการ์ด (หรือเปิดการ์ดแล้วกด ✋ ฉันจะทำงานนี้ ก็ได้)
  2. เปิด Claude Code ในโฟลเดอร์โค้ดเกม แล้วพิมพ์ เช่น
    • ทำการ์ด GeckoBoard ที่ฉันรับไว้ทั้งหมด (หลายใบ)
    • ทำการ์ด #12 ให้หน่อย (ใบเดียว)
  3. Claude จะอ่านการ์ด แก้โค้ด แล้วย้ายการ์ดไป พร้อมเทส พร้อมสรุปและวิธีเทสให้ Tester
  4. ถ้าไม่ใช้ Claude: เปิดการ์ดแล้วกด ➡ ส่งไปพร้อมเทส (หรือลากการ์ดไปคอลัมน์พร้อมเทส) แล้วกรอกสิ่งที่ทำกับวิธีเทสให้ Tester ได้เอง
  5. ตรวจโค้ดที่ Claude แก้ก่อน commit (Claude ไม่ commit/push เองถ้าไม่สั่ง)
  6. ถ้า Tester ตีกลับ ให้สั่งใหม่ เช่น ทำการ์ด #12 ใหม่ ดูคอมเมนต์ที่ tester ทิ้งไว้
ติดงานไม่ไหว? กด ปล่อยการ์ด เพื่อให้คนอื่นรับต่อ
Tester: เทสและปิดงาน
  1. ดูคอลัมน์ พร้อมเทส แล้วเปิดการ์ด
  2. อ่านหัวข้อ 🧪 วิธีเทส ทำตามขั้นตอนทีละข้อ
  3. เทสตามขั้นตอนที่เขียนไว้ ถ้าไม่เจอปัญหา กด ✓ ผ่าน → เสร็จสิ้น ปุ่มเดียวจบ
  4. ถ้าติดตรงไหน กด ✗ ไม่ผ่าน แล้วพิมพ์ว่าเจออะไร (วางรูปแคปหน้าจอด้วย Ctrl+V ได้) การ์ดจะกลับไปกำลังทำ และข้อความจะถูกบันทึกเป็นคอมเมนต์ให้ Dev เห็น
  5. ถ้างานที่ปิดไปแล้วมีปัญหากลับมา กด เปิดใหม่
Admin: จัดการทีม
  1. คลิกชื่อมุมขวาบน → ทีมและสิทธิ์
  2. เพิ่มคนใหม่ด้วยอีเมล Google + เลือก role: dev / tester / admin
  3. คนที่ไม่อยู่ในรายชื่อจะ login ไม่ได้ เปลี่ยน role หรือลบคนออกได้ในหน้าเดียวกัน
  4. ถ้าคนรับงานไปแล้วทำไม่ได้ เปิดการ์ดแล้วกด ปล่อยการ์ดจาก … เพื่อดึงคืน
ฟีเจอร์อื่นๆ
  • ลากการ์ดข้ามคอลัมน์ได้: เปิด→กำลังทำ (รับงาน), กำลังทำ→เปิด (ปล่อย), พร้อมเทส→เสร็จสิ้น หรือกลับไปกำลังทำ (Tester)
  • ค้นหา/กรอง ที่แถบใต้หัวเว็บ: ค้นหา ความสำคัญ tag คนรับ milestone
  • วางรูปได้ทุกที่: แคปหน้าจอแล้วกด Ctrl+V ที่หน้าบอร์ดเพื่อสร้างการ์ดใหม่พร้อมรูป หรือวางตอนเปิดการ์ด/ฟอร์มสร้างการ์ดเพื่อแนบเพิ่ม วางได้หลายรูป (สูงสุด 20 ไฟล์ต่อการ์ด)
  • ไฟล์แนบ: ลากไฟล์มาวางในการ์ดก็ได้ รูปจะถูกย่อให้อัตโนมัติ และ Claude ดูรูปได้ผ่าน MCP · ไฟล์ต้นฉบับของงานที่เสร็จนานแล้วจะถูกรีไซเคิลอัตโนมัติเมื่อพื้นที่ใกล้เต็ม (เหลือรูปตัวอย่างไว้) กด 📌 เพื่อปักหมุดไฟล์สำคัญ
  • วันกำหนดส่ง / Milestone ตั้งตอนสร้างหรือแก้ไขการ์ด ใบที่เลยกำหนดจะขึ้นสีแดง
  • ลิงก์การ์ด: ตั้งการ์ดแม่/การ์ดย่อย หรือเชื่อมการ์ดที่เกี่ยวข้องกัน
  • แท็กคนในคอมเมนต์ด้วย @ชื่อ และกระดิ่ง 🔔 สรุปสิ่งที่เกี่ยวกับคุณ
  • แจ้งเตือน Discord เมื่อพร้อมเทส / เทสไม่ผ่าน / เสร็จสิ้น / ถูกแท็ก (เมื่อ admin ตั้งค่าไว้)
  • คัดลอกเป็นข้อความ ในหน้าการ์ด เพื่อส่งต่อให้คนนอกระบบ · 📊 สรุป ดูภาพรวมของทีม
Role ทำอะไรได้บ้าง
  • dev: สร้าง/ลบการ์ด รับ/ปล่อยการ์ด ส่งพร้อมเทส (เอง หรือผ่าน Claude)
  • tester: ผ่าน / ไม่ผ่าน / เปิดใหม่
  • admin: ทำได้ทุกอย่าง + จัดการทีม
  • ทุก role สร้างการ์ดและคอมเมนต์ได้
Everyone: create a card
  1. Click + New and pick Ticket (bug / request) or Task (work to do)
  2. Add a title, description (steps to reproduce, expected result), priority and tags. The more detail, the better Claude's fix
  3. Use the Mine / Unassigned filters to find your own cards or cards nobody has picked up
Dev: pick up work and ask Claude First-time setup
  1. Click your name (top right) → Connect Claude (MCP), press Copy and run the command in a normal terminal (not in a chat with Claude). No clone or install needed
  2. No claude command on your machine? Open No `claude` command in the same dialog and paste the JSON into ~/.claude.json
  3. Restart Claude Code and type /mcp to check geckoboard shows as connected
  4. The token is personal. Never share it or paste it into a chat. If it leaks, click Regenerate token
Every time you work
  1. Tick the checkbox on a card on the main board to claim it (it moves to In Progress). Take as many as you like, but each card can have only one owner: a card someone already took shows a lock and their name. Untick to release (or open the card and click ✋ I'll do this)
  2. Open Claude Code inside the game's code folder and type, for example
    • Do all the GeckoBoard cards I claimed (multiple)
    • Do GeckoBoard card #12 (single)
  3. Claude reads the card, fixes the code, then moves it to Ready to Test with a summary and test steps for the tester
  4. Not using Claude? Open the card and click ➡ Send to Ready to Test (or drag it to the Ready to Test column) and fill in what you did and the test steps yourself
  5. Review the code Claude changed before committing (Claude won't commit/push unless you ask)
  6. If the tester sends it back, ask again, e.g. Redo GeckoBoard card #12, see the tester's comment
Stuck? Click Release so someone else can take the card
Tester: test and close
  1. Look at the Ready to Test column and open a card
  2. Read 🧪 How to test and follow the steps one by one
  3. Follow the test steps. If nothing is wrong, click ✓ Pass → Complete. One click, done
  4. If you get stuck anywhere, click ✗ Fail and type what you saw (you can paste a screenshot with Ctrl+V). The card goes back to In Progress and your note is saved as a comment for the dev
  5. If a closed card turns out to be broken, click Reopen
Admin: manage the team
  1. Click your name (top right) → Team & roles
  2. Add people by Google email and choose a role: dev / tester / admin
  3. People not on the list can't sign in. Change roles or remove people on the same screen
  4. If the owner can't finish, open the card and click Release from … to take it back
More features
  • Drag cards between columns: Open→In Progress (claim), In Progress→Open (release), Ready to Test→Complete or back to In Progress (testers)
  • Search / filter in the bar under the header: search, priority, tag, owner, milestone
  • Paste images anywhere: take a screenshot, then press Ctrl+V on the board to start a new card with it, or paste while a card / the new-card form is open to attach more. Several images at once are fine (up to 20 files per card)
  • Attachments: you can also drop files onto a card. Images are shrunk automatically and Claude can look at them through MCP · Originals of long-finished cards are recycled automatically when space runs low (a preview is kept). Pin 📌 important files
  • Due date / Milestone when creating or editing a card. Overdue cards turn red
  • Links: set a parent / sub-cards, or link related cards
  • Mention people in comments with @name; the 🔔 bell summarises what concerns you
  • Discord alerts on ready to test / test failed / complete / mentions (when an admin has set it up)
  • Copy as text in the card to share outside the tool · 📊 Summary for the team overview
What can each role do?
  • dev: create/delete cards, claim/release, send to Ready to Test (by hand or via Claude)
  • tester: Pass / Fail / Reopen
  • admin: everything + manage the team
  • Every role can create cards and comment
