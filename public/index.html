ทุกคน: สร้างการ์ด
  1. กด + สร้างการ์ด เลือก Ticket (บั๊ก/คำขอ) หรือ Task (งานที่ต้องทำ)
  2. ใส่หัวข้อ รายละเอียด (ขั้นตอนทำซ้ำ ผลที่คาดหวัง) ความสำคัญ และ tag ยิ่งละเอียด Claude ยิ่งแก้ตรงจุด
  3. ใช้ปุ่มกรอง ของฉัน / ยังไม่มีคนรับ เพื่อหางานของตัวเองหรืองานที่ยังไม่มีคนรับ
Dev: รับงานแล้วสั่ง Claude ตั้งค่าครั้งแรก
  1. คลิกชื่อมุมขวาบน → เชื่อมต่อ Claude (MCP) กด คัดลอก แล้วเอาคำสั่งไปรันใน terminal ธรรมดา (ไม่ใช่ในแชตกับ Claude) ไม่ต้อง clone หรือติดตั้งอะไร
  2. เปิด Claude Code ใหม่ แล้วพิมพ์ /mcp เช็กว่า geckoboard ขึ้น connected
  3. Token เป็นของคุณคนเดียว ห้ามแชร์หรือวางในแชต ถ้าหลุดให้กด สร้าง token ใหม่
ทุกครั้งที่ทำงาน
  1. ติ๊กช่องสี่เหลี่ยมที่การ์ดบนหน้าหลัก เพื่อรับงาน (การ์ดย้ายไปกำลังทำ) เลือกได้หลายใบ แต่ การ์ด 1 ใบมีคนรับได้ 1 คน ถ้ามีคนรับไปแล้วจะขึ้นรูปกุญแจและชื่อคนที่รับ ติ๊กออกเพื่อปล่อยการ์ด (หรือเปิดการ์ดแล้วกด ✋ ฉันจะทำงานนี้ ก็ได้)
  2. เปิด Claude Code ในโฟลเดอร์โค้ดเกม แล้วพิมพ์ เช่น
    • ทำการ์ด GeckoBoard ที่ฉันรับไว้ทั้งหมด (หลายใบ)
    • ทำการ์ด #12 ให้หน่อย (ใบเดียว)
  3. Claude จะอ่านการ์ด แก้โค้ด แล้วย้ายการ์ดไป พร้อมเทส พร้อมสรุปและวิธีเทสให้ Tester
  4. ตรวจโค้ดที่ Claude แก้ก่อน commit (Claude ไม่ commit/push เองถ้าไม่สั่ง)
  5. ถ้า Tester ตีกลับ ให้สั่งใหม่ เช่น ทำการ์ด #12 ใหม่ ดูคอมเมนต์ที่ tester ทิ้งไว้
ติดงานไม่ไหว? กด ปล่อยการ์ด เพื่อให้คนอื่นรับต่อ
Tester: เทสและปิดงาน
  1. ดูคอลัมน์ พร้อมเทส แล้วเปิดการ์ด
  2. อ่านหัวข้อ 🧪 วิธีเทส ทำตามขั้นตอนทีละข้อ
  3. ผ่านหมด → กด ✓ ผ่าน → เสร็จสิ้น
  4. ไม่ผ่าน → กด ✗ ไม่ผ่าน พร้อมเหตุผล การ์ดกลับไปกำลังทำ และเหตุผลจะถูกบันทึกเป็นคอมเมนต์
  5. ถ้างานที่ปิดไปแล้วมีปัญหากลับมา กด เปิดใหม่
Admin: จัดการทีม
  1. คลิกชื่อมุมขวาบน → ทีมและสิทธิ์
  2. เพิ่มคนใหม่ด้วยอีเมล Google + เลือก role: dev / tester / admin
  3. คนที่ไม่อยู่ในรายชื่อจะ login ไม่ได้ เปลี่ยน role หรือลบคนออกได้ในหน้าเดียวกัน
  4. ถ้าคนรับงานไปแล้วทำไม่ได้ เปิดการ์ดแล้วกด ปล่อยการ์ดจาก … เพื่อดึงคืน
  5. ลบการ์ด: เปิดการ์ด แล้วกด 🗑 ลบการ์ด (เฉพาะ admin ลบแล้วกู้คืนไม่ได้)
Role ทำอะไรได้บ้าง
  • dev: รับ/ปล่อยการ์ด ส่งพร้อมเทส (ผ่าน Claude)
  • tester: ผ่าน / ไม่ผ่าน / เปิดใหม่
  • admin: ทำได้ทุกอย่าง + จัดการทีม + ลบการ์ด
  • ทุก role สร้างการ์ดและคอมเมนต์ได้
Everyone: create a card
  1. Click + New and pick Ticket (bug / request) or Task (work to do)
  2. Add a title, description (steps to reproduce, expected result), priority and tags. The more detail, the better Claude's fix
  3. Use the Mine / Unassigned filters to find your own cards or cards nobody has picked up
Dev: pick up work and ask Claude First-time setup
  1. Click your name (top right) → Connect Claude (MCP), press Copy and run the command in a normal terminal (not in a chat with Claude). No clone or install needed
  2. Restart Claude Code and type /mcp to check geckoboard shows as connected
  3. The token is personal. Never share it or paste it into a chat. If it leaks, click Regenerate token
Every time you work
  1. Tick the checkbox on a card on the main board to claim it (it moves to In Progress). Take as many as you like, but each card can have only one owner: a card someone already took shows a lock and their name. Untick to release (or open the card and click ✋ I'll do this)
  2. Open Claude Code inside the game's code folder and type, for example
    • Do all the GeckoBoard cards I claimed (multiple)
    • Do GeckoBoard card #12 (single)
  3. Claude reads the card, fixes the code, then moves it to Ready to Test with a summary and test steps for the tester
  4. Review the code Claude changed before committing (Claude won't commit/push unless you ask)
  5. If the tester sends it back, ask again, e.g. Redo GeckoBoard card #12, see the tester's comment
Stuck? Click Release so someone else can take the card
Tester: test and close
  1. Look at the Ready to Test column and open a card
  2. Read 🧪 How to test and follow the steps one by one
  3. All good → click ✓ Pass → Complete
  4. Not working → click ✗ Fail with a reason. The card goes back to In Progress and the reason is saved as a comment
  5. If a closed card turns out to be broken, click Reopen
Admin: manage the team
  1. Click your name (top right) → Team & roles
  2. Add people by Google email and choose a role: dev / tester / admin
  3. People not on the list can't sign in. Change roles or remove people on the same screen
  4. If the owner can't finish, open the card and click Release from … to take it back
  5. Delete a card: open it and click 🗑 Delete (admin only, cannot be undone)
What can each role do?
  • dev: claim/release cards, send to Ready to Test (via Claude)
  • tester: Pass / Fail / Reopen
  • admin: everything + manage the team + delete cards
  • Every role can create cards and comment
